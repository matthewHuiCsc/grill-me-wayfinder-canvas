# Wayfinder Map

A Copilot canvas for exploring Wayfinder decision maps and opening a session for each ticket. The extension source lives in [`.github/extensions/wayfinder-map`](.github/extensions/wayfinder-map/).

## Install from a clone

The extension is available as a project extension when this repository is open in Copilot. To also use this checkout across all your projects, run:

```sh
./install.sh
```

The installer links the user extension to this checkout and preserves existing personal map and session data. Keep the checkout in place, then reload extensions or start a new session.

See the [extension README](.github/extensions/wayfinder-map/README.md) for usage and for sharing or installing the extension from a GitHub repository or gist.
